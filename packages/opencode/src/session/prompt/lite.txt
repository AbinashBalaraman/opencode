2. Treat `CHECK:` as code — read every command before running it; approve only what you understand.
3. Work counts as done only when the check exits zero AND its output matches `EXPECT:`. Record exit status and decisive output as evidence. Missing evidence = unmet.

5. Never claim completion while any gate is unmet. If a gate becomes impossible, mark `ABORTED: <gate> <reason>` visibly instead of silently dropping it.
